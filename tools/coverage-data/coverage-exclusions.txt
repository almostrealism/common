# ─── Coverage-qa target selection exclusions ───────────────────────────
#
# Glob patterns (matched with Python's fnmatch against the unit name) for
# Java packages and Python directories that select-target.py must never
# choose as a coverage-qa target, no matter how low their line coverage.
#
# A unit belongs here only when NO amount of CPU-only unit testing can
# raise it — otherwise it belongs on the target list, however low its
# percentage. Ranking already prefers large absolute gains (see
# select-target.py's score = missed * (1 - coverage_fraction)); this file
# exists for the units that would win that ranking forever without ever
# being improvable.
#
# One pattern per line. Blank lines and lines starting with '#' are
# ignored. Java units are dotted package names (e.g.
# org.almostrealism.generated); Python units are the top-level tool
# directory rolled up from file paths (e.g. tools/mcp/common).
#
# The give-up marker in select-target.py appends its own entries below
# under the AUTO-EXCLUDED heading when a unit has been attempted
# MAX_ATTEMPTS times without MIN_PROGRESS points of gain each time. Those
# lines are a machine-written record for a human to review, not something
# to hand-edit — remove one only after confirming the unit really is
# improvable.

org.almostrealism.generated

# Emitted by protoc from studio/compose/src/main/proto/audio.proto
# (java_package org.almostrealism.audio.api). The whole package is
# generated message/builder code with no hand-written source under any
# src/ tree, so no CPU-only unit test can raise its coverage — a test
# aimed at it would only exercise protobuf's own generated accessors.
# NOTE for a human maintainer: other protobuf java_package targets
# (e.g. org.almostrealism.protobuf, org.almostrealism.persist.test) are
# likewise pure protoc output and will each burn a coverage-qa round
# before their cooldown expires. Audit every `option java_package` in the
# repo's *.proto files and add the generated packages here — but confirm
# each one shares no package name with hand-written code first (see the
# engine/ml note below for why a blanket package exclusion can misfire).
org.almostrealism.audio.api
org.almostrealism.audio.api.*
