# Ingest allowlist — the CLOSED SET of files permitted to call the MemoryData /
# PackedCollection read(ByteBuffer) / read(InputStream) ingest surface.
#
# This is the single source of truth shared by two enforcement points, which read
# this exact file rather than keeping their own copies:
#   - SetMemLiteralsDetector (engine/utils), rule INGEST_OUTSIDE_SANCTIONED_SURFACE,
#     loads it as a classpath resource.
#   - .claude/hooks/block-computed-ingest.py, the PreToolUse block, reads it from
#     this path in the working tree.
#
# read(ByteBuffer)/read(InputStream) is the sanctioned route for data ENTERING the
# process from OUTSIDE it (deserialization, file and network I/O). A file that is
# not listed here may not call that surface at all: values Java has computed must
# reach device memory through a Producer, never by staging them in a buffer and
# shipping them through the ingest surface. Every entry names the outside source it
# reads; add one only for a genuine outside-the-process deserializer.
#
# The allowlist suppresses ONLY rule INGEST_OUTSIDE_SANCTIONED_SURFACE. The rule
# COMPUTED_VALUE_STAGED_FOR_INGEST still applies to every file below — allowlisting
# a deserializer does not license staging host-computed values through it (that is
# what stops the evasion from simply moving into an allowlisted file).
#
# Format: one path fragment per line, matched as a substring of the file path
# exactly as SANCTIONED_WRITE_SURFACE is. Text after '#' is a justification comment.

/persist/assets/CollectionEncoder.java              # decodes a serialized protobuf Collections.CollectionData message into a collection
/hardware/external/LocalExternalMemoryProvider.java # reads a memory image back from an on-disk binary file
/GraphPersist.java                                  # reconstructs a collection from a database blob in the persisted graph store
/hardware/test/MemoryDataSerializationTest.java     # exercises the read(ByteBuffer) ingest surface as its explicit subject under test
